# DMM/WSD 분석 및 이식 범위

이 문서는 `xr-stream-app` 저장소 안에서 DMM/WSD 이식 보고서의 범위와 검증 한계를 자체 완결적으로 설명한다. 외부 작업 디렉터리나 분석자 PC의 절대 경로를 요구하지 않는다.

## 권한 근거

- `auth.status`: `granted`
- `basis`: 사용자가 소유한 Android XR 앱, 합법적으로 사용하는 DMM 계정과 구매 콘텐츠, 사용자가 제공한 APK 및 공개 테스트 WSDCF
- 목적: 지원되지 않는 사용자 소유 Android XR 헤드셋에서 정상 로그인과 정상 WSD 권리 검사를 거쳐 구매 콘텐츠를 재생할 수 있는지 호환성을 연구

이 권한은 DMM 서비스 약관, WSD 런타임의 재배포 조건 또는 제3자 저작권을 대신 판단하지 않는다. 저장소 소유자는 비공개 저장소 밖으로 바이너리를 배포하기 전에 별도로 권리를 확인해야 한다.

## 포함 범위

- 사용자 제공 DMM Android APK의 오프라인 정적 분석
- WSD DEX 및 ARM64 네이티브 라이브러리의 형식·클래스·호출 경계 확인
- Jetpack XR 앱의 WebView 로그인, WSDCF 다운로드/스트리밍 연결, Rights-Issuer, Media3 연결 구현
- 공개 테스트 WSDCF와 사용자가 구매한 콘텐츠를 이용한 사용자 통제 물리 기기 검증 절차 작성
- 저장소 소스, 리소스, 문서, 바이너리 해시의 비컴파일 정적 검사

## 제외 범위

- 계정, 비밀번호, JWT, 쿠키 또는 토큰 수집 및 저장소 저장
- DRM 우회, 콘텐츠 키 추출, 라이선스 실패·만료·출력 제한 우회
- 다른 사용자의 계정이나 콘텐츠 접근
- DMM 운영 서비스에 대한 자동화된 운영망 시험, 스캔, 부하 시험
- Codex CLI에서 Gradle build/test/install 또는 Android SDK를 이용한 컴파일

## 네트워크 및 데이터 처리

- `network_profile`: `lab_only`
- DMM 운영 서버의 로그인·다운로드·권리 발급은 분석 서버가 대신 실행하지 않는다.
- 실제 로그인과 재생 검증은 사용자가 자신의 물리 헤드셋에서 수행한다.
- 로그에는 URL query/fragment, 쿠키, 토큰을 남기지 않으며 공유 전 다시 확인한다.
- 실제 자격증명은 Git, properties, 문서, 이슈에 기록하지 않는다.

## 완료 기준

정적 구현 완료와 실제 기능 완료를 구분한다.

- 정적 구현 완료: WebView→download/stream→WSD→Media3 경로, DEX/SO 포함, 문서와 정적 검사가 준비됨
- 실제 기능 완료: 물리 헤드셋에서 로그인, 직접 스트리밍, 다운로드, 유효 권리를 사용한 오프라인 재생이 모두 재현됨

현재 보고서는 첫 번째 기준만 충족했다고 기록하며 두 번째 기준은 미검증 상태로 유지한다.
